# حبكان — Habkan Reel

ريل تعريفي (موشن جرافيك) لبراند **حبكان**: وكالة لتصميم وتطوير وإعادة بناء متاجر سلّة وزد وShopify.
الفكرة إن حبكان بتبني متجر بيبيع مش مجرد تصميم: تبدأ بالعميل (مين هو؟ وش يقلقه؟ وليش بيشتري؟) والسوق والمنافسين.

## السكريبت (سعودي، نبرة نفسية)
صرفت على المتجر... ودفعت لمصمّم... وجلست تنتظر أول طلب. يوم ورا يوم... الزيارات تجي، والسلة فاضية.
وتبدأ تسأل نفسك: العيب فيني؟ في منتجي؟ ولا في السوق؟ لا... العيب مو فيك.
متجرك انصمم عشان يعجبك... مو عشان يقنع عميلك. المتجر الحلو ما يبيع لحاله... المتجر اللي يبيع، وراه حَبْكة.
في حَبْكان، ما نبدأ بالألوان... نبدأ بعميلك: مين هو؟ وش يقلقه؟ وليش بيشتري؟
نقرأ السوق، ونفكّك منافسينك، ونبني كل صفحة على قرار الشراء... من أول نظرة، لين إتمام الطلب.
تصميم، تطوير، وإعادة بناء متاجر... سلّة، وزد، وشوبيفاي. لا تخسر أكثر... خلّ حَبْكان تَحبِك لك متجر... يبيع.

الفويس اتراجع كلمة بكلمة بـ Whisper large-v3-turbo قدام السكريبت: 94 من 94 كلمة صح.
الأرقام والأسماء اللي في الفيديو (متجر ريم، الطلبات، الفاتورة) كلها من الخيال.

## إعادة البناء
```bash
cd habkan/tools && npm install && node build_logo2.mjs build          # اللوجو + أجزاء اللوجو للفيديو
cd ../audio && python3 make_audio2.py                                 # الصوت (numpy + scipy)
cd ../tools && node render2.js 1080 1920 30 ../scratch/fv 4           # فريمات 9:16
node render2.js 1920 1080 30 ../scratch/fh 4                          # فريمات 16:9
ffmpeg -framerate 30 -i ../scratch/fv/f%05d.jpg -i ../audio/mix2.wav -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 256k ../out/habkan-reel-9x16.mp4
```
النسخة الأولى (الفيديو الأفقي القديم) موجودة في `video/` و`audio/make_audio.py` للرجوع ليها.
