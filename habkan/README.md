# حبكان — Habkan Brand Film

فيديو تعريفي (موشن جرافيك) لبراند **حبكان**: وكالة لتصميم وتطوير وإعادة بناء متاجر سلّة وزد وShopify،
بتبني "سيستم بيبيع" مش مجرد تصميم — بتبدأ بفهم السوق والمنافسين والعميل (مين هيشتري وليه).

## الملفات
| | |
|---|---|
| `out/habkan-brand-film-1080p.mp4` | الفيديو النهائي — 1920×1080، 60fps، 57 ثانية، صوت AAC (‎-14 LUFS) |
| `brand/` | اللوجو: أيقونة، نسخة أفقية، نسخة رأسية — SVG + PNG |
| `video/` | مشاهد الموشن (HTML/SVG بتتحرك بدالة `render(t)`) |
| `audio/make_audio.py` | الموسيقى والمؤثرات (مقام حجاز: عود + درابوكة مقسوم + بادز) + مكساج مع التعليق الصوتي |
| `tools/` | بناء اللوجو (HarfBuzz) والرندر (Playwright → ffmpeg) |

## الهوية
- **اللوجو**: كلمة "حبكان" بخط كوفي (Reem Kufi) متشكّلة بـ HarfBuzz، النقط اتشالت واتبدلت بنقطة الخط العربي المعيّنة —
  نقطة الباء بالزعفراني هي "التفصيلة اللي بتفرق". الرمز "عقدة حبكان": نجمة ثمانية من مربعين منسوجين فوق/تحت = الحَبْك.
- **الألوان**: حبر `#0F0E13` · رملي `#F4EBDD` · زعفران `#FFB43C` → حِنّة `#E9542B`
- **الخطوط**: Reem Kufi (اللوجو) · Alexandria (العناوين والنصوص) · Space Grotesk (اللاتيني)

## القصة (57 ثانية)
ليان فتحت متجرها الأول — تصميم أنيق ومنتجات رائعة، لكن محدش بيشتري → المشكلة مش في الشكل، في **الحبكة** →
ظهور حبكان → "مين هيشتري؟ وليه؟" → نقرأ السوق، نحلل المنافسين، نفهم العميل → نحبك كل ده في نظام واحد من أول نظرة لإتمام الطلب →
بعد 30 يوم القصة اتغيرت (طلبات بتنزل) → تصميم · تطوير · إعادة بناء — سلّة · زد · Shopify → **حبكان: لا نصمم متجرًا فقط. نبني متجرًا يبيع.**

التعليق الصوتي: ElevenLabs (صوت عربي فصحى). القصة والبراند والمتجر "ليان" والأرقام كلها من الخيال.

## إعادة البناء
```bash
cd habkan/tools && npm install && node build_logo.mjs      # اللوجو
python3 ../audio/make_audio.py                             # الصوت (numpy + scipy)
node render.js ../scratch/frames 60 4                      # الفريمات
ffmpeg -framerate 60 -i ../scratch/frames/f%05d.jpg -i ../audio/mix.wav -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 256k ../out/habkan-brand-film-1080p.mp4
```
